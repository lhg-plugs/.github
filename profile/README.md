# lhg-plugs

小白专家插件市场：每个插件整合某垂直方向最佳 skill/工具，小白一句话调用。

一键安装整个市场：

```
/plugin marketplace add lhg-plugs/marketplace
```

安装单个插件：

```
/plugin marketplace add lhg-plugs/<插件名>
```
